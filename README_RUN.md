
# MediaHub — Run & Debug

## First run (Windows)
1. Double‑click **FIRST_RUN.cmd** (creates `.venv`, installs dependencies).
2. Then use **RUN_SERVER.cmd** or **RUN_SERVER_DEBUG.cmd**.
3. Optional: place **aria2c.exe** and/or **qbittorrent.exe** into `bin\` or set their paths in **settings.html**.

## First run (macOS / Linux)
```bash
chmod +x first_run.sh run_server.sh run_server_debug.sh run_all.sh
./first_run.sh
./run_server.sh
```
(Use `./run_server_debug.sh` to keep logs noisy).

## Connectors
- Configure endpoints/tokens in the app: **Settings → Connectors** (no code edits required).
- To auto‑start engines locally, put the binaries here: `bin/aria2c.exe`, `bin/qbittorrent.exe` (Windows) or `bin/aria2c`, `bin/qbittorrent` (*nix).

## Scripts overview
- **FIRST_RUN.cmd / first_run.sh** — creates venv and installs `requirements.txt`.
- **RUN_SERVER.cmd / run_server.sh** — launches Flask server (port 5000).
- **RUN_SERVER_DEBUG.cmd / run_server_debug.sh** — same, but with extra diagnostics; window stays open.
- **RUN_ALL.cmd / run_all.sh** — starts optional aria2/qB if binaries found, then server.
- **STOP_ALL.cmd / stop_all.sh** — attempts to stop server and optional engines.


## Codecs & Tools (FFmpeg, 7-Zip)
- Use **GET_FFMPEG.cmd / get_ffmpeg.sh** to fetch portable ffmpeg (or install via package manager).
- Use **GET_7ZIP.cmd / get_7zip.sh** to fetch portable 7‑Zip.
- Configure explicit paths in **Settings → FFmpeg / 7‑Zip**, or leave blank to auto-detect (`./bin` or system PATH).
- Test in **Tools → Check** and **HLS Test**.


## Thumbnails & Audio Transcode
- **Thumbnails**: Tools → Thumbnails → provide a video path and interval; generates a poster and VTT of thumbs under `storage/tmp/thumbs/<id>/`.
- **Audio Transcode**: Tools → HLS Test (video) or call `/api/stream/audio?path=...&format=mp3&br=192` for on‑the‑fly audio streaming.


- **Hero auto-poster**: home hero now requests autogenerated posters from your local files (via thumbs ensure).
- **Collections timeline previews**: rows show poster previews; thumbs are generated on-demand.

## Gate N (Smart Rails — LIVE)
