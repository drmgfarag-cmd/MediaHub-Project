- **Storage:** 2GB minimum for full installation
- **Network:** Internet connection for metadata and streaming

### **Quick Start**
```bash
# Extract the build
unzip MediaHub_Ultimate_Complete_Final_ALL_PHASES.zip
cd MediaHub_Ultimate_Complete_Final/server
```
